# InfoServ2A — démarrer le projet Hermes dans Cursor

Version documentaire 1.0 — 7 septembre 2026.

Le dossier de référence du collaborateur virtuel InfoServ2A est dans **[docs/hermes-collaborateur/README.md](docs/hermes-collaborateur/README.md)**.

Il couvre l'ensemble de l'activité : pilotage de l'entreprise, relation client, rendez-vous, devis, facturation et suivi comptable, développement web et logiciel, Claire, opérations réseau et cyber, interventions, documentation, médias et continuité de service.

**Point de départ pour Cursor :** lire [00-LIRE-EN-PREMIER.md](docs/hermes-collaborateur/00-LIRE-EN-PREMIER.md), puis [02-existant-et-inconnues.md](docs/hermes-collaborateur/02-existant-et-inconnues.md) et le [plan de réalisation](docs/hermes-collaborateur/18-plan-de-realisation.md).

Ce dépôt contient ici une **spécification et un dossier de reprise**, pas une infrastructure installée. Les nouveaux services et contrats d'API y sont proposés, sauf mention explicite d'une capacité existante vérifiée. La présence de cette documentation ne déclenche aucune connexion, commande de VPS, dépense, publication de site, invitation ou opération comptable.

Prompt de reprise :

> Lis HERMES-CURSOR-START.md puis docs/hermes-collaborateur/00-LIRE-EN-PREMIER.md. Intègre le périmètre global d'InfoServ2A à ton analyse. Commence par le lot L0 d'inventaire : confronte les documents au dépôt et à la machine où tu travailles, vérifie les accès disponibles sans exposer de secrets et produis un état factuel. Explique les écarts avec la cible. Pour les lots d'implémentation ensuite autorisés, exécute le travail jusqu'à sa recette, avec preuves et compte rendu, en respectant les autorisations déjà données dans notre session.

Le dossier est conçu pour évoluer par versions. Les informations privées d'exploitation restent dans les espaces privés de l'entreprise ; les exemples du dossier public utilisent des valeurs fictives ou à renseigner.
