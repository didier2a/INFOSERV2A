# Maquette d’arrivée — logo + deux portes

**Statut :** maquette seulement. Rien n’est publié sur www.  
**Figma :** [InfoServ2A — Arrivée Claire](https://www.figma.com/design/T2z2xKceCkXggQ9eYPbGts)

## Intention

Claire reste la **devanture** : on a envie de lui parler.  
Le logo InfoServ2A enlève le « je me suis trompé de site ».  
La deuxième porte (« Voir le site d’abord ») n’est pas une sortie de secours : c’est feuilleter le magasin, sans micro.

## Ce que ce n’est pas

Pas le 1 (mail it38), pas le 2 (apex), pas le remplacement de l’arrivée production.  
Décision à prendre sur le ton et les libellés avant d’implémenter sur www.
