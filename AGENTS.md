# INFOSERV2A — Instructions permanentes du projet

## Sources obligatoires

Avant toute création ou modification, lire :

- `site-map.json`
- `docs/01-direction-visuelle.md`
- `docs/02-audit-ux-responsive.md`
- `docs/03-contenus-editoriaux.md`
- `docs/04-navigation-interactions.md`
- `docs/05-acceptance-checklist.md`
- le PNG de référence de la page active dans `assets/images/references/`

## Ordre de priorité

1. Le PNG définit la composition, les proportions, l’ordre des sections et l’atmosphère.
2. `docs/03-contenus-editoriaux.md` définit les textes canoniques.
3. `docs/02-audit-ux-responsive.md` définit l’aération, le responsive et la réduction de densité.
4. `docs/04-navigation-interactions.md` définit les cartes, les liens, les accordéons et la navigation.
5. Le code existant peut être adapté lorsqu’il empêche le respect des quatre sources précédentes.

## Méthode

Pour chaque page :

1. Lire le PNG.
2. Lire le contenu canonique correspondant.
3. Produire un plan de sections.
4. Intégrer en HTML/CSS/JS réel.
5. Lancer le serveur local.
6. Comparer avec le calque `?ref=1`.
7. Corriger la structure, puis les espacements, puis la typographie, puis les détails.
8. Tester desktop, tablette et mobile.
9. Vérifier les interactions et l’accessibilité.
10. Valider la page avant de passer à la suivante.

## Objectif visuel

Conserver le design bleu nuit / cyan, les cartes sombres, les bordures lumineuses fines, les illustrations technologiques et la sensation premium. Réduire cependant la densité visible d’environ 20 à 30 % par l’espacement, la hiérarchie et le déploiement progressif des contenus.
