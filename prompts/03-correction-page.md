# Prompt Cursor — Correction ciblée d’une page

Corrige uniquement la page active et son CSS spécifique.

Référence officielle : utilise le PNG déclaré dans `site-map.json`.

Priorité des corrections :

1. structure ;
2. largeur des conteneurs ;
3. hauteur des sections ;
4. espacements ;
5. grille ;
6. typographie ;
7. cartes ;
8. CTA ;
9. détails décoratifs.

Contraintes :

- ne pas modifier les autres pages ;
- ne pas réécrire les textes canoniques ;
- ne pas casser le header, le footer ni la navigation ;
- maintenir l’aération prévue ;
- maintenir le responsive ;
- tester avec `?ref=1` ;
- signaler précisément les fichiers modifiés.
