10. IMAGES ET FONDS
==================================================

Utiliser les images importées dans assets/images comme références.

Ne pas créer de nouveaux visuels externes.
Ne pas télécharger d’images.
Ne pas remplacer les maquettes par des visuels génériques.

Pour chaque page :
- utiliser le PNG correspondant comme référence visuelle ;
- si nécessaire, utiliser une image de la maquette ou un fond existant comme background décoratif ;
- privilégier un rendu proche des PNG ;
- ne pas figer toute la page en image ;
- le texte doit rester HTML.

Si les images de maquettes sont trop grandes, les optimiser par CSS :
object-fit: cover;
background-size: cover;
background-position: center;
overlay sombre par ::before ou gradient.

Ne pas utiliser d’alerte navigateur agressive.
Afficher le message dans la page.
